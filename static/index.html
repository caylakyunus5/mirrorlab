Tek dosya HTML olarak kaydet

Sayfa, tüm CSS'i ve mümkün olduğunca çok varlığı içine gömülü şekilde tek bir .html dosyasına dönüştürülür — internet olmadan açılır.
İndirme başlamadıysa (gömülü önizleme çerçevesi indirmeleri engelleyebilir): bu bağlantıya tıklayın ya da uygulamayı tarayıcıda yeni sekmede açın.

Nasıl çalışıyor?

1. Çekme
Sayfa tarayıcı kimliğiyle sunucuda çekilir, yönlendirmeler takip edilir, charset doğru çözülür.
2. Ayrıştırma
HTML ayrıştırılır; src / href / srcset / poster / data-* ve CSS içi url() adresleri bulunur.
3. Gömme
CSS dosyaları içindeki görseller de çözülüp base64 data-URI olarak HTML'in içine yazılır.

Tam site aynası (ZIP)

Siteyi bağlantıları takip ederek gezer, sayfaları + CSS/JS/görsel/font varlıklarını indirir ve yerel göreli bağlantıları düzeltip ZIP olarak paketler. ZIP'i açtığınızda index.html ile çevrimdışı gezinirsiniz.
